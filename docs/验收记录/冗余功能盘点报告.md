# 冗余功能盘点报告（2026-10-16）

> 作者原话：「全面检查是否有冗余的功能，影响使用」。
> 本报告只做盘点，**不动任何代码** —— 按你的习惯，删什么、留什么由你拍板，
> 你点哪条我就改哪条。

盘点范围：5 个主视图（TopBar 视图页签）、12 个右侧 dock 面板、10 个对话框、顶栏/移动栏全部按钮。

---

## 一、真重复（同一个目的、两条入口、内容大面积重叠）

### 1. 「统计」有两个家：dock 面板 vs 主视图 —— 重叠度：高

| | dock「统计」`StatsPanel.vue` | 主视图「统计」`StatsView.vue` |
|---|---|---|
| 数据来源 | `core/stats` 的 loadDaily / recentDays / summarize | 同一个 |
| 展示内容 | 总字数、章节/卷、今日、连续写作、今日目标进度、近 N 天字数曲线、分卷字数、状态分布、最长/最短章 | **上面全都有**，另外多：活跃日均、自定义统计规则（插件/统计.json）、结构健康度（已定稿率/待修/空章/断更）、章节字数分布 |

结论：StatsView 是 StatsPanel 的超集。作者在 dock 里能看到的每一项，主视图里都有且更全；
而 dock 那个还少三块信息。两个入口都常驻（dock 页签一排 + 顶栏视图页签），点哪个都能到。

**建议**：删掉 dock 的「统计」页签，只留主视图「统计」。
理由：dock 面板的定位是「写作时随手够得着的小工具」，统计是「坐下来看一眼」的事，
放主视图更合适；留着一个信息更少的副本，只会让人疑心「这两个数字怎么不一样」。

## 二、近似重复（目的接近、内容部分重叠，留着有理由但值得你知道）

### 2. 「看板」BoardView vs 「章节目录」ChapterTree —— 重叠度：中

- ChapterTree：写作时选章节、建卷建章、看每章状态标签。
- BoardView：同一批章节按「待写/草稿/待修/已定稿」分四列，拖拽改状态。
- 重叠在「都能改状态、都能跳章」；但看板多的是「一眼看全书进度分布」，目录树多的是「随时切章写作」。
- **建议保留两个**，不算冗余。若日后要精简，优先动的也是别的地方。

### 3. 「资料」AssetPanel vs 「设定库」CodexPanel —— 重叠度：中

- AssetPanel：编辑「大纲/」「设定/」「记忆/」下的**文件内容**（现在默认停在大纲分类）。
- CodexPanel：管理「设定/&lt;分类&gt;/&lt;名称&gt;.md」**条目**，带 AI 生成设定。
- 重叠：都能改设定目录里的 md。差别是「按文件改」vs「按条目管 + AI 推荐」。
- **建议保留两个**，但 AssetPanel 默认分类已是「大纲」，「资料」这个名字容易和「设定」混，
  可考虑改名「文件」或「大纲与资料」。

### 4. 「检查」CheckPanel vs 「伏笔」ForeshadowPanel —— 重叠度：低

- CheckPanel 会报「伏笔超期」，ForeshadowPanel 管伏笔台账本身。
- 一个是**报问题**，一个是**管数据**，互相引用，不算重复。保留。

### 5. 「关系图」GraphView vs 「时间线」TimelineView —— 重叠度：低

- 图看「谁和谁有关系」，时间线看「事件按顺序发没发生矛盾」。不同维度。保留。

## 三、入口层的小问题（不是重复，但「影响使用」）

### 6. 大纲相关三个入口，职责要说清

| 入口 | 位置 | 干什么 |
|---|---|---|
| 大纲对话框 OutlineDialog | 顶栏「大纲」 | **写/改**全书大纲与卷纲（可编辑） |
| 📖 全书大纲 / 📑 分卷大纲 OutlineViewDialog | 章节目录顶端 / 每卷第一章上方 | **只读翻阅**，写作时瞄一眼 |
| 📖 资料面板 → 大纲 | dock「资料」 | 按文件编辑大纲内容 |

三者目的不同（写 / 瞄 / 管文件），是这次按你的诉求特意加的，不算冗余。
唯一风险是「大纲」两个字出现在三处，作者可能找不到想用的那个 —— 靠文案区分，不建议合并。

### 7. 备份 / 导出 / 沙盒导出 三条 zip 路

- BackupDialog：整个作品打成 zip 备份到磁盘。
- ExportDialog：生成 docx / md / txt / epub 稿子（投稿用）。
- SandboxDialog：沙盒（浏览器降级模式）里把内存镜像导出成 zip 落磁盘。
- 目的各不相同，**都保留**。

### 8. 移动栏按钮过少

MobileBar 只有「收起 / 大纲 / 撤销」。桌面顶栏的「导入稿件 / 导入大纲 / 查找 / 参考 / 快照 / 导出 / 设置」
在手机上要开「收起」才够得到。这是适配问题不是冗余，但确实「影响使用」——
手机上建议至少把「查找」和「导入」提上来。
