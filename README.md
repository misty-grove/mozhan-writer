# 墨栈写作台

> 离线优先的中文网文写作台 · 你的稿子就是磁盘上的文件夹

一款为**写长篇小说**设计的本地写作软件。核心主张只有两条：

- **文件即数据。** 一章一个 Markdown 文件，没有私有格式、没有数据库、没有账号锁定。随时能用记事本打开、拷进 U 盘、打包带走。
- **离线优先。** 打开就是编辑器，不联网也能写完整本书。设定库、伏笔台账、一致性检查、文风分析、关系图、时间线、统计、搜索 —— **全部本机计算，0 token**。AI 只是可选的一层，不填 Key 就不出现。

---

## 特色

| | |
|---|---|
| **纯文件存储** | 章节是普通 `.md`，目录结构清晰可读，换任何工具都拿得走 |
| **离线能力拉满** | 9 个资料面板全部本地运算，不花一分钱 token |
| **AI 可选** | 支持任何 OpenAI 兼容服务商（DeepSeek / 智谱 / Kimi / 通义 / OpenAI / Ollama…），AI 产出先进候选区，你点了才进正文 |
| **一致性守护** | 双链断链、角色失踪、伏笔超期、时序矛盾、疑似笔误 —— 全书对账 |
| **五个视图** | 写作 / 看板 / 关系图 / 时间线 / 统计，同一份数据不同切面 |
| **多端宿主** | 桌面（Tauri）/ 浏览器（Chrome/Edge）/ 安卓，同一套业务代码，文件系统抽象成 `FsAdapter` |
| **一键导入** | 几十万字旧稿 txt 直接拖进来，自动认编码、切章、预览、落盘 |
| **多种导出** | Markdown / TXT / DOCX / EPUB3，另支持自定义模板插件 |

## 快速开始

### 下载安装（推荐）

到 [Releases](../../releases) 页面下载最新安装包：

- **Windows**：`..._x64-setup.exe`（约 1.6 MB，装当前用户，不要管理员）
- **安卓**：`....apk`

### 从源码运行

```bash
npm install
npm run dev          # 打开提示的 http://127.0.0.1:5173
```

需要 **Node 20+**。浏览器版推荐 **Chrome / Edge**（能直接读写本机文件夹）。

> Firefox / Safari 会自动切到「沙盒模式」，代价写在应用首页里。

### 打桌面安装包

```bash
npm run desktop:build    # 产物在 <target>/release/bundle/
```

> 桌面版用 **GNU 工具链**（不是 MSVC），配置与踩坑见 [开发文档 §6](开发文档.md)。

## 验收体系

改坏了会不会被发现，答案在这几层里：

```bash
npm run verify:all     # typecheck + selfcheck + smoke + e2e（四层）
npm run rust:verify    # 动了 Rust 才需要
npm run e2e:desktop    # 要出安装包时跑
```

- **typecheck** — 类型检查（`src/` 与 `scripts/` 一起查）
- **selfcheck** — 核心层纯逻辑断言，内存文件系统，不联网、不要浏览器
- **smoke** — jsdom 里把每个面板/视图挂载一遍，抓渲染期报错
- **e2e** — 真 Chrome，真 File System Access API，真键盘真鼠标
- **e2e:desktop** — 真 WebView2 窗口 + 真磁盘 IPC

> 大作品规模（300 章 / 85 万字）专门压测过：关系图 0.08s、一致性检查 0.31s。
