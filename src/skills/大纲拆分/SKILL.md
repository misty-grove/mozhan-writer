# 大纲拆分

把"大概要写什么"变成"哪一章写什么"。

## 输入

- 全书/本卷目标（一句话或一段话）
- 已确定的分卷结构（若有）
- 现有章节与记忆摘要（避免重复）

## 流程

1. 先复述你对目标的理解，一句话说清这一卷要解决的核心问题。
2. 设计**冲突链**：每一章都要把局势推向不可逆，不能一章平地一步。
3. 按"起 — 承 — 转 — 合"给这一卷分配章节，标注每章功能（铺垫 / 升级 / 转折 / 高潮 / 缓冲）。
4. 为每一章写出章纲条目。

## 章纲条目格式（每条必须填满）

```
### 第NNN章 标题
- 功能：（铺垫/升级/转折/高潮/缓冲）
- 目标：这一章要达成的一件事
- 出场：（人物，用设定库原名）
- 涉及设定：（列出会用到的设定条目）
- 情绪走向：（起点 → 落点）
- 钩子：结尾留什么没解决
```

## 硬要求

- 相邻两章的情绪不能有两次连续的同质高峰，必须有缓冲章。
- 涉及设定库没有的新名词，标注"（待补设定）"，不要默默引入。
- 不写结尾总结与客套话。
