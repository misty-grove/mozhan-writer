# 文风仿写

目标不是"写得好"，而是"写得像这个人写的"。

## 提取文风指纹

从参考文本里提取以下维度，用表格列出，作为后续写作的锚点：

| 维度 | 观察点 |
|---|---|
| 句长分布 | 平均句长、长短句交替节律、是否有超长句 |
| 段落结构 | 每段几句、对话是否独立成段 |
| 对话配比 | 对话 vs 叙述的大致占比 |
| 人称视角 | 第一/第三人称，限制视角还是全知 |
| 用词层级 | 书面/口语、是否有方言、惯用的动词强弱 |
| 标点习惯 | 引号样式、破折号与省略号频率 |
| 描写偏好 | 重动作还是重心理，感官类型（视觉/听觉/嗅觉） |
| 高频句式 | 作者反复使用的句式模板 |

## 仿写规则

- 句长分布向参考文本靠拢：参考文本平均 30 字，就不要写出平均 15 字或 60 字的段落。
- 复刻作者的**开头习惯**（例如惯用动作开场还是对话开场）。
- 保留作者的**口头禅与转场方式**。
- 作者的惯用词优先，同义词只在重复三次以上时才替换。

## 禁忌（这些会让文风立刻"变 AI"）

- 排比句连用三句以上
- 四字成语叠堆
- "仿佛整个世界都安静了""他心中五味杂陈"这类总结腔
- 每段末尾都加一句抒情总结
- 形容词叠用（"冰冷却又温柔的光"）

## 输出

先给出指纹表格（不超过表格 + 8 条要点），再按要求产出正文。
