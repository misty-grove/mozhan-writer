# 目录对照表（离线写作工作台）

本应用的作品就是一个**普通文件夹**，没有私有格式，记事本也能改。目录即数据模型。
下面这张表是唯一权威——需要定位任何文件时先在这里查，不要凭别的工具的惯例猜。

## 一、本应用的结构（作品根目录）

| 路径 | 是什么 | 谁在写 |
|:--------------------|:------------------------------------------------------------|:------------------------|
| `作品信息.md` | 书名 / 作者 / 一句话简介 / 目标字数 | 作者、应用 |
| `大纲/大纲.md` | 全书大纲：分卷 + 每卷章纲（表格） | 作者、AI 候选采纳 |
| `大纲/` 下其他 `.md` | 分卷大纲、人物大纲、剧情大纲等 | 作者、导入 |
| `设定/` | 人物设定、世界设定等条目（`.md`） | 作者、导入 |
| `正文/第NNN章 标题.md` | 章节正文，一章一个文件 | 作者、AI 采纳 |
| `记忆/逐章摘要.md` | 每章一段事实摘要 | AI 逐章摘要采纳 |
| `记忆/滚动总述.md` | 越写越长的全书总述 | AI 采纳 |
| `记忆/状态表.md` | 人物状态（伤势/位置/持有物/关系） | AI 采纳、作者手改 |
| `记忆/伏笔台账.md` | 伏笔埋设与回收登记 | AI 采纳、作者手改 |
| `记忆/时间线.md` | 故事内事件时序 | AI 采纳 |
| `记忆/文风基线.md` | 从作者已写正文里抽出的文风样本 | 应用自动生成 |
| `技能/` | 本作品专用技能（同名覆盖全局与内置） | 作者 |
| `.snapshots/` | 应用自动快照，**隐藏目录**，不要动 | 应用 |

## 二、路径对照（外部技能写法 → 本应用实际路径）

其他小说写作工具/技能习惯下面这些名字。**遇到时照这张表翻译，不要新建目录**。

| 别的工具习惯写法 | 本应用的实际路径 |
|:---------------------------------|:---------------------------------------------|
| `book.md` / `project.md` | `作品信息.md` |
| `spec/outline/book.md` | `大纲/大纲.md` |
| `spec/outline/volume-XX.md` | `大纲/` 下的分卷大纲 `.md` |
| `spec/outline/chapters/<章>.md` | `大纲/大纲.md` 里该章的章纲行（**不单独建文件**） |
| `spec/characters/*.md` | `设定/` 下的人物设定条目 |
| `spec/worldbuilding/*.md` | `设定/` 下的世界设定条目 |
| `stories/第NNN章.md` / `chapters/` | `正文/第NNN章 标题.md` |
| `memory/chapter-summaries.md` | `记忆/逐章摘要.md` |
| `memory/story-so-far.md` | `记忆/滚动总述.md` |
| `memory/state.md` / `tracking/*.json` | `记忆/状态表.md`、`记忆/伏笔台账.md` |
| `memory/timeline.md` | `记忆/时间线.md` |
| `skills/` | `技能/` |
| `drafts/`、`manuscript/` | 没有对应目录——正文就在 `正文/` |

## 三、硬规矩（比对照表更重要）

1. **找不到 `spec/`、`memory/`、`stories/` 不等于作品是空的。**
   先按上表翻译成 `大纲/`、`记忆/`、`正文/` 再看。判定"新项目/记忆没落盘"之前，
   必须先确认这两套名字都查过了——误判会让作者觉得"AI 变笨了"。
2. **不要新建 `spec/` 之类的外来目录。** 这会让同一个作品出现两套结构，作者下次打开
   应用看不见新写的东西。
3. **章纲不单独成文件。** 每章的纲要在 `大纲/大纲.md` 的表格行里；正文才一章一个文件。
4. **`记忆/` 下由应用自动维护的内容包着 `<!-- writer:xxx -->` 标记。**
   只改标记之间的部分，标记外的作者手写内容**一个字都不要动**，否则会覆盖作者的笔记。
5. **写入正文只有一个入口**：应用会把 AI 的产出先放进候选区，作者点「采纳」才落盘。
   所以默认应当**产出文本交回候选区**，而不是直接改 `正文/`。
6. **文件名里不要出现路径分隔符**，也不要 `..`、`C:`、Windows 保留名（`con`/`nul` 等）——
   应用侧会拒绝，白写一次。
