# 记忆整理

记忆库是长篇不崩的前提，也是续写上下文的来源。宁可**写得平实准确**，也不要写得漂亮。

## 一、逐章摘要（100–200 字）

必须包含：
- 发生了什么（事实，不评价）
- 谁在场
- 谁改变了主意 / 得到了什么 / 失去了什么
- 本章结尾未解决的东西

禁止：抒情、形容词、"这一章情绪饱满""伏笔深厚"这类空话。

## 二、状态表更新

```
| 人物 | 变化类型 | 变化内容 | 章节 |
```
变化类型限于：受伤 / 康复 / 获得 / 失去 / 位置移动 / 关系变动 / 得知秘密。

## 三、伏笔登记

```
| 伏笔 | 埋设章节 | 状态 | 计划回收 | 优先级 |
```
- 本章新埋的伏笔 → 状态「未回收」
- 本章回收的伏笔 → 状态「已回收」，并写明回收章节

## 四、时间线抽取

```
| 故事内时间 | 事件 | 在场角色 | 章节 |
```
故事内时间不明就写「未标注」，不要猜。

## 输出顺序

依次输出：摘要 → 状态表 → 伏笔 → 时间线。四部分都要有，缺的部分写「本章无」。
